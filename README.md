# Развязка / 03

Модульный шаблон градостроительной транспортной стратегии на pointy-top аксиальной гексагональной сетке. Чистое ядро TypeScript, процедурная Three.js-сцена и React 19 HUD. Все модели, материалы и геометрия создаются локально.

## Запуск

Требуется **Node.js 24+** (встроенное исполнение TypeScript в тестах).

```sh
npm ci
npm test
npm run build
npm run dev
```

`npm run build` выполняет строгую проверку TypeScript, Vite-сборку и создаёт `PLAY.html` в корне и `dist/PLAY.html`. Файл содержит весь JavaScript и CSS, без CDN, импортов моделей и внешних шрифтов. Для игры достаточно открыть `PLAY.html` в современном браузере с WebGL2. Локальный HTTP-сервер для разработки: адрес выводится командой `npm run dev`.

Сборщик проверяет отсутствие внешних script/link-ресурсов, fetch и сетевых CSS-ресурсов. Полифилл modulepreload отключён для автономной сборки. `package-lock.json` фиксирует зависимости. Runtime-зависимости: только `react`, `react-dom`, `three`; тестовый раннер — встроенный `node:test`.

## Управление

- WASD / правая кнопка мыши — панорамирование; колесо — масштаб.
- R / кнопка ↻ — поворот на 60°; M — бумажная стратегическая карта.
- Пробел — пауза; кнопки 1× / 2× / 4× — скорость игрового времени.
- Инструменты слева — дороги, эстакады, рампы, светофоры, четыре вида зон и снос.
- Переключатель «Земля / Эстакада» определяет редактируемый уровень, включая светофор и снос. Дорога/Эстакада выбирают соответствующий уровень автоматически.
- Клик размещает объект. Для улицы зажмите ЛКМ и проведите маршрут: соединяются только пройденные пары гексов. Для ответвления начните с существующей дороги, для замыкания закончите на ней. Соседние улицы автоматически не соединяются.
- Цифры 0–9 выбирают инструменты, Esc возвращает обзор. Снос также можно протягивать мышью.
- Для рампы выбрать направление 0..300° и длину 2..6 шагов, затем нажать на её наземный конец. Обратное движение и спуск разрешены автоматически.

**Семантика длины:** `rampSpan = N` — N межцентровых интервалов по гексагональной оси, то есть N+1 адресов, включая оба конца. Фактическая длина подъёма — `N * sqrt(3) * HEX_SIZE`; UI явно показывает и шаги, и число занятых гексов. Таким образом подъём никогда не укладывается в один межцентровый интервал.

## Правила графа

- В одном гексе существуют два независимых RoadCell: `ground` и `elevated`. Совпадение координат не создаёт связи между уровнями.
- Редактор явно соединяет выбранные соседние дороги одного уровня. Высота полотна берётся из общего поля рельефа вне скальных разрывов, поэтому дорога проходит через разные высоты без разрыва на грани гекса. Слишком крутые маршруты отклоняются до строительства.
- Рампа — прямой коридор по одной из шести осей. Каждый шаг подъёма добавляет 2 м: 2–6 шагов дают 4–12 м относительно входа. Профиль сглажен и сопрягается с уклоном входа. Продолжение эстакады сохраняет достигнутую абсолютную высоту.
- У подъёма на эстакаду начальный узел — ground, остальные — elevated; у соединения террас все узлы — ground. Интерьер рампы резервирует обе позиции: под низкой частью подъёма нельзя разместить наземную дорогу. Под полноценным пролётом можно.
- Проверка рампы атомарна: диапазон/целочисленность длины, занятость, границы региона, прямые подключения концов и допустимый уклон с шагом проверки не более 0,5 м по продольному профилю проверяются до изменений.
- Снос части рампы удаляет рампу целиком, включая её конечные узлы. Нижняя независимая дорога под пролётом сохраняется.
- Elevated допускает прямое движение и повороты ±60°. Развороты разрешены только в округлых тупиках на обоих уровнях. На самой рампе движение прямое; съезд с поворотом размещается в соседнем узле.
- A* ищет путь по directed lanes. Терминальные половины полос служат началом/концом поездки. Продольная координата `u` измеряет длину 3D-пути, включая подъём.
- Удаление части сети отменяет затронутые поездки без начисления доставки; новые поездки используют текущий граф.

## Симуляция и демонстрационная экономика

Фиксированный шаг — 1/30 секунды. IDM учитывает скорость, безопасную дистанцию, относительную скорость лидера и уклон. Параметры легковых машин и грузовиков различаются. Проверка лидеров охватывает следующие полосы и терминальные половины полос. Дополнительный предел перемещения предотвращает проникновение в лидера при аварийном сближении.

Светофоры переключают существующие встречные пары либо отдельные въезды. Длительность зелёного задаётся в панели; жёлтый и общий красный длятся по секунде. Конфликтующие траектории резервируются до освобождения задней частью машины; непересекающиеся встречные полосы могут использовать гекс одновременно.

Районы автоматически получают доступ через грань к наземной дороге. Поездки идут Home → Shop → Home и Factory → Warehouse → Shop. Доставки начисляются один раз; прогресс хранится на гексах, поэтому объединение/разделение кластера не создаёт его заново. Throughput — доход за скользящее окно 30 игровых секунд.

## Проверки

`npm test` покрывает координаты, все шесть направлений, маски и независимость уровней, допустимые/недопустимые рампы, атомарность отказа, рельеф, непрерывность полос, запрет разворотов, маршруты A*, районы, торможение, доставку, удаление маршрута, бюджет и пятиминутный прогон стартового города.

Сцена проверена через браузер: изображение, рост счётчика доставок, пауза, стратегическая карта, поворот, строительство двух уровней в одном гексе, снос верхнего с сохранением нижнего и размещение рампы. Ошибок в консоли браузера не обнаружено. Прямую проверку `file://` инструмент браузера не разрешил; собранный `PLAY.html` проверен через локальный HTTP. Сетевые ресурсы в автономном файле отсутствуют по статической проверке сборки.

## Границы шаблона

Это архитектурный шаблон с интерактивной демонстрацией, не завершённая кампания. Нет сохранения между запусками, undo/redo, MOBIL/перестроений, инженерного расчёта мостов и точной конфликтной матрицы перекрёстков. Геометрия конфликтов использует дискретное семплирование аналитических траекторий. Рампы прямые; криволинейный подъём и автоматический поиск места для съезда не реализованы. Рендер не гарантирует отсутствие любых артефактов на всех произвольных построениях.

- [OpenTTD](https://github.com/OpenTTD/OpenTTD) — концепция уровней, мостов и явных переходов.

- [A/B Street](https://github.com/a-b-street/abstreet) — направленные полосы и фазы пересечений; здесь используется упрощённая самостоятельная модель.
- [Road Network Generator](https://github.com/alexandengstrom/road-network-generator) — представление сети узлами и связями; стартовые узлы демонстрации заданы детерминированно.

Код этих проектов не включён в исходники шаблона.

## Процедурный рельеф

«Генерация карты» в панели слева принимает целочисленное зерно и создаёт новую игру. Одинаковое зерно воспроизводит карту; новые постройки при генерации сбрасываются. По умолчанию используется 23.

Мировая отметка моря — 0 м. Русло может лежать ниже неё; вода отображается на единой горизонтальной поверхности. Начальная площадка — 4 м; вокруг неё смешиваются два масштаба seed-зависимого шума и речная долина. Гексы являются адресами поверхности, а не независимыми плоскими столбиками. На общих границах рендер, полосы и машины получают высоту из одной функции. Строка состояния показывает высоту земли и уклон под курсором.

Наземная дорога следует рельефу. Эстакада сохраняет абсолютную отметку выхода рампы; минимальный просвет — 3 м. Отдельно поставленная эстакада начинается на 6 м выше земли. Предельный уклон 70% — игровое ограничение. Опоры доходят до земли в своей точке, полотно имеет толщину и отбрасывает тень.

Единица высоты соответствует магазину — 6 м. Перепады до этой величины сглаживаются; более высокие перепады разделены скальными стенками. Обычная дорога через скалу запрещена. Для соединения террас выберите рампу «Соединить уровни земли» и длину 2–6 шагов до второй площадки. Рампа вырезает или насыпает коридор и соединяет наземные дороги. Туннели пока не реализованы.

Сохранение мира и ручное редактирование рельефа пока не реализованы.

## Новые настройки перекрёстка

В режиме «Обзор» щёлкните дорогу выбранного уровня. Плавающая панель перетаскивается за заголовок и закрывается крестиком или Escape. Инструмент «Светофор» устанавливает светофор за 30 Cr и открывает панель. Повторный щелчок не отключает его. Установка из панели также стоит 30 Cr; смена работающего режима и настройка правил бесплатны.

Светофор перебирает только существующие въезды: встречные пары либо каждый въезд отдельно. Зелёный настраивается от 3 до 30 секунд, затем идут 1 секунда жёлтого и 1 секунда красного для всех. Новый въезд на жёлтый запрещён; уже въехавшие машины завершают манёвр. Эти режимы заменяют прежний фиксированный трёхфазный цикл.

Работающий светофор отменяет главную дорогу, но левый поворот уступает разрешённому встречному движению. Без светофора главными автоматически становятся два самых ранних сохранившихся соединения узла. Можно выбрать главные въезды вручную либо вернуть автоматический выбор. Между равнозначными въездами действует помеха справа; замкнутое ожидание разрешается по прибытии.

Левый поворот на перекрёстке запрещён до включения в панели. Изгиб дороги с двумя подключениями не считается перекрёстком. Запреты учитывает поиск маршрута. При смене правил машины по возможности перестраивают будущую часть маршрута; если пути нет, ждут перед запрещённым манёвром. Уже начатый проезд не прерывается, занятость сохраняется до выхода задней части машины.

Схема показывает вид сверху, номера въездов и сигналы. Настройки наземного и верхнего узлов независимы. Генерация новой карты сбрасывает правила вместе с постройками.
