# Улицы и редактор — исправление по пользовательской схеме

Проблема: автоматически связывались все соседние дорожные гексы. В плотной застройке это создавало треугольную решётку. Рендер рисовал каждый гекс набором радиальных отрезков, даже при обычном повороте.

Изменения:
- Игровой граф использует explicit-режим (`new HexRoadGraph(terrain, inside, false)`). Только `connect(a,b)` добавляет связь. Режим автоматического соединения сохранён как совместимый низкоуровневый вариант для генераторов и старых тестов, но редактор его не использует.
- Зажатая ЛКМ прокладывает последовательный маршрут. При быстром движении пропущенные координаты заполняются hexLine. Два соседних маршрута не соединяются сами.
- Для ответвления надо начать жест на существующей улице. Для замыкания — закончить на ней. После отпускания мыши начинается новый независимый маршрут.
- Поворот с двумя выходами получает цельную дугу с постоянной шириной. Бортики, разметка и направленные полосы следуют согласованной аналитической геометрии. Поездки района начинаются/заканчиваются на этой дуге.
- Подключение к рампе предварительно валидируется. Ошибка не создаёт бесплатную дорогу и не переносит точку продолжения рисования.
- HUD заменён компактным редактором: строка показателей сверху, инструменты и уровень слева, состояние и скорость снизу. Рекламный блок, лозунги, крупные карточки и декоративные метрики убраны. Иконки — локальные SVG.

Проверки: explicit-связи, угол из трёх соседних гексов без лишней диагонали, сохранение масок после удаления, отказ бокового подключения к рампе без изменения карты/бюджета, размещение access-lanes на дуге. Сохраняются тесты обоих уровней, рамп, IDM и длительного движения.
