# Визуальный стенд промышленных зданий

Откройте `scripts/preview-buildings.html` двойным щелчком. Three.js, OrbitControls, стили и модели встроены в HTML; сервер, CDN и внешние ассеты не нужны. Через существующий Vite доступен URL `http://127.0.0.1:5173/scripts/preview-buildings.html`.

- ЛКМ — вращение, колесо — масштаб, ПКМ — перемещение.
- Нижние кнопки: общая коллекция или отдельная модель.
- Верхние кнопки: проекция, сброс вида, автовращение, экспорт PNG.
- Тени и экспозиция регулируются независимо.

Исходники: `models.js` — геометрия и материалы, `scene.js` — свет, камеры и управление, `shell.html` — интерфейс.
После правок выполните из корня:

```sh
node scripts/build-preview-buildings.mjs
```

Используется esbuild из уже установленного дерева зависимостей Vite. Версии зависимостей проекта не менялись.

Контуры оснований вычисляются объединением граней 1, 3 или 7 правильных гексов; внутренние грани удалены. Детали процедурные: двускатная фальцевая и пилообразная кровля, доки, грузовики, грузы, сосны. Контактные тени и маркировка создаются CanvasTexture локально. Художественная интерпретация референсов 01-buildings.png и 04-merged-complex.png, без импорта игровой логики. Стенд намеренно не изменяет игровые меши и не симулирует поставки.
